OBS Studio Plugin · Windows 64-bit · Direct3D 11 + DirectML

CamAr Studio OBS

Filtro profesional de belleza y retoque facial en tiempo real para OBS Studio. Tracking síncrono de 0 retraso, color 1:1 passthrough y aceleración total por GPU sin modificar archivos de OBS.

Arquitectura y Ventajas Clave

0 ms de Desfase

Downsample GPU a 270p y tracking síncrono sobre el mismo frame N con DirectML (478 landmarks + iris + blendshapes).

Color 1:1 Passthrough

Respeta intacta la gama y el espacio de color de OBS para combinarlo sin cambios de tono junto a tus LUTs o filtros de color.

Dependencias Aisladas

Carga su propia copia privada camar_onnxruntime.dll + DirectML.dll; cero conflictos con obs-backgroundremoval.

Binario Protegido

30 shaders HLSL precompilados en bytecode DXBC, sin código HLSL en texto plano ni símbolos de depuración.

Instalación

  1. Descarga la última versión desde GitHub Releases: elige el Instalador (CamAr-OBS-vX.Y.Z-Setup.exe) o el Portable (CamAr-OBS-vX.Y.Z-Portable.zip).
  2. Cierra OBS Studio antes de instalar.
  3. Si usas el instalador .exe, detectará automáticamente tu carpeta de OBS Studio (o usa Examinar... para instalaciones portables). Si usas el .zip, extrae obs-plugins/ y data/ en la raíz de OBS.
  4. Al abrir OBS verás brevemente el popup animado de carga mientras los modelos IA se inicializan en DirectML sin congelar la interfaz.

Configuración en OBS Studio

  1. Haz clic derecho sobre tu fuente de cámara (o escena de cámara) → Filtros.
  2. En Filtros de efecto pulsa + y selecciona CamAr Studio Beauty Filter.
  3. Cámaras verticales: si la cámara entra horizontal (1920×1080) antes de rotarla en el lienzo, ajusta 🔄 Rotación de Cámara (para Tracker IA) a 90° (Vertical Derecha) o 270° (Vertical Izquierda).
  4. Orden recomendado: mantén CamAr Studio Beauty Filter como primer filtro y aplica tus filtros de color/LUT después.
